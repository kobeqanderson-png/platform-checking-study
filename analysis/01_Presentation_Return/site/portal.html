02 / Return, then return again

Frequency is
only one dimension.

A placement return, a visit near the old goal, and another goal-reaching round trip answer different questions. Read each animal’s sequence before reducing it to a count.

Complete round tripFirst old-goal entry on that tripIncomplete segment
Interpretation

Repeated returns are relevant to the study of compulsive checking. Repetition alone does not establish compulsion. Return timing, intervening behavior, context and sensitivity to changed conditions remain separate questions.
